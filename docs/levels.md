# 1. Purpose

This document defines the expected characteristics of English learners at each CEFR level supported by English Tests.

The supported levels are:

```text
A1
A2
B1
B2
C1
C2


The purpose of this document is to establish a consistent reference for:

Diagnostic Tests;
Level Tests;
Vocabulary Practice;
Question creation;
Difficulty classification;
Results interpretation;
Learning recommendations.

This document is not intended to reproduce the complete CEFR framework.

It provides a practical product-oriented interpretation that can be used when creating and reviewing English Tests content.

2. CEFR Overview

The CEFR divides language proficiency into six main levels:

Basic User
├── A1
└── A2

Independent User
├── B1
└── B2

Proficient User
├── C1
└── C2

The progression can be understood broadly as:

A1 → Can communicate in very basic situations.

A2 → Can communicate in familiar everyday situations.

B1 → Can handle many everyday and familiar situations independently.

B2 → Can communicate independently with greater fluency and complexity.

C1 → Can use English effectively and flexibly for complex communication.

C2 → Can understand and express virtually everything with a very high degree of precision.

These descriptions are intentionally broad.

A learner's actual ability may vary between skills.

For example:

Overall: B1

Reading: B2
Grammar: B1
Vocabulary: B1
Listening: A2
Writing: A2

Therefore, English Tests must not assume that all skills develop at exactly the same speed.

3. Important Principle: Level Is Not a Single Skill

A CEFR level represents overall language ability, but individual skills can develop differently.

The application should therefore support profiles such as:

Overall: B1

Grammar: B1
Vocabulary: B1
Reading: B2
Listening: A2
Writing: A2/B1

The Diagnostic Test should use this principle when generating results.

4. A1 — Beginner
4.1 General Description

A1 represents the beginning stage of English learning.

A learner at A1 can understand and use very basic expressions and communicate in simple situations when the other person speaks clearly and provides support.

Communication is strongly dependent on:

familiar vocabulary;
predictable situations;
short sentences;
simple structures;
repetition;
visual or contextual support.
4.2 A1 Communication

An A1 learner can generally:

introduce themselves;
give basic personal information;
ask and answer simple questions;
talk about family;
describe basic daily activities;
identify common objects;
talk about likes and dislikes;
communicate basic needs;
understand very simple instructions.

Example:

My name is Ana. I am from Colombia. I live in Bogotá. I am a student.

4.3 A1 Grammar

Typical grammatical areas include:

verb be;
subject pronouns;
possessive adjectives;
basic present simple;
basic questions;
basic negatives;
imperatives;
singular and plural nouns;
basic articles;
basic demonstratives;
basic prepositions;
there is / there are;
can for basic ability;
simple conjunctions such as and, but, or.

Grammar tasks should prioritize fundamental structures rather than complex transformations.

4.4 A1 Vocabulary

Vocabulary is primarily concrete and familiar.

Typical topics:

family;
home;
school;
food;
numbers;
colors;
days and months;
clothes;
jobs;
common places;
transportation;
everyday objects;
basic activities.

Vocabulary should generally be understandable through context or familiar situations.

4.5 A1 Reading

An A1 learner can understand very short and simple texts.

Examples:

signs;
menus;
short messages;
simple profiles;
basic schedules;
labels;
short descriptions.

Questions should focus mainly on:

identifying information;
recognizing familiar words;
understanding simple sentences;
matching information.
4.6 A1 Listening

Listening should use:

slow or clearly articulated speech;
short utterances;
familiar vocabulary;
predictable contexts.

The learner should be able to identify:

names;
numbers;
times;
places;
basic instructions;
simple personal information.
4.7 A1 Writing

Writing activities should be highly controlled.

Possible tasks:

complete a sentence;
write personal information;
write simple sentences;
describe a person or object;
answer simple questions.

Example:

Write three sentences about yourself.

4.8 A1 Difficulty Characteristics

A1 activities should generally have:

short prompts;
clear instructions;
familiar vocabulary;
limited grammatical complexity;
strong contextual support;
minimal ambiguity.

Images can be especially useful at this level.

5. A2 — Elementary
5.1 General Description

A2 represents the ability to communicate in common everyday situations using simple language.

The learner can understand and produce basic connected language about familiar topics.

Compared with A1, the learner should demonstrate greater independence and a wider range of vocabulary and structures.

5.2 A2 Communication

An A2 learner can generally:

describe routines;
talk about past experiences;
discuss plans;
describe people and places;
make simple requests;
give basic opinions;
explain simple problems;
handle common travel situations;
discuss familiar activities.
5.3 A2 Grammar

Typical areas include:

present simple;
present continuous;
past simple;
future forms;
basic present perfect;
comparatives and superlatives;
countable and uncountable nouns;
quantifiers;
modal verbs;
adverbs of frequency;
common prepositions;
basic conjunctions;
basic relative clauses;
first conditional;
basic question structures.

Grammar tasks should increasingly require understanding of context.

5.4 A2 Vocabulary

Vocabulary expands into familiar everyday areas.

Possible topics:

travel;
shopping;
health;
work;
education;
hobbies;
weather;
transportation;
food;
relationships;
technology;
daily routines.

The learner should increasingly understand common expressions and common word combinations.

5.5 A2 Reading

An A2 learner can understand short texts containing familiar language.

Possible materials:

emails;
short articles;
advertisements;
simple stories;
schedules;
messages;
instructions;
descriptions.

Tasks can include:

identifying main information;
finding specific details;
understanding simple relationships;
identifying basic meaning from context.
5.6 A2 Listening

Listening may include:

short conversations;
announcements;
simple interviews;
everyday situations;
short narratives.

Speech can be moderately natural but should remain accessible.

5.7 A2 Writing

Possible tasks:

short emails;
descriptions;
personal messages;
short narratives;
simple opinions;
descriptions of past events.

Example:

Write a short message to a friend describing your weekend.

5.8 A2 Difficulty Characteristics

Compared with A1:

Longer prompts
+
More vocabulary
+
More contextual interpretation
+
More grammatical variety
+
Less visual support

However, tasks should still focus primarily on familiar situations.

6. B1 — Intermediate
6.1 General Description

B1 represents the transition toward independent English use.

The learner can understand the main points of clear standard language and communicate in many everyday, travel, educational and work-related situations.

The learner can produce connected language rather than relying only on isolated sentences.

6.2 B1 Communication

A B1 learner can generally:

describe experiences;
tell stories;
explain plans;
give opinions;
give reasons;
describe problems;
discuss familiar topics;
handle travel situations;
participate in everyday conversations;
write connected texts.
6.3 B1 Grammar

Typical areas include:

present and past forms;
present perfect;
future forms;
modal verbs;
first and second conditionals;
passive voice;
reported speech basics;
relative clauses;
gerunds and infinitives;
linking words;
comparative structures;
question structures;
common phrasal verbs.

Grammar should increasingly be tested through context rather than isolated rule recognition.

6.4 B1 Vocabulary

Vocabulary should cover:

work;
education;
travel;
technology;
relationships;
environment;
society;
media;
health;
lifestyle;
personal experiences.

The learner should understand common:

collocations;
phrasal verbs;
idiomatic expressions;
word families.
6.5 B1 Reading

Texts can include:

articles;
blogs;
emails;
narratives;
informational texts;
opinions;
workplace communication.

Tasks should begin to require:

inference;
understanding attitude;
contextual vocabulary;
identifying main ideas;
identifying supporting information.
6.6 B1 Listening

Listening can include:

natural conversations;
interviews;
short talks;
everyday discussions;
narratives.

Speech may include different accents or more natural pacing, while remaining generally accessible.

6.7 B1 Writing

Possible tasks:

emails;
opinion paragraphs;
narratives;
descriptions;
informal/formal messages;
short essays.

The learner should increasingly demonstrate:

organization;
connected ideas;
appropriate vocabulary;
understandable grammar.
6.8 B1 Difficulty Characteristics

B1 is an important transition point.

Activities should increasingly require the learner to:

Understand context
+
Connect information
+
Infer meaning
+
Produce connected language
+
Choose appropriate language

Questions should not be limited to simple grammar recognition.

7. B2 — Upper-Intermediate
7.1 General Description

B2 represents confident independent language use.

The learner can understand the main ideas of complex texts and interact with fluent speakers with a reasonable degree of fluency.

The learner can discuss abstract and technical topics within their area of knowledge.

7.2 B2 Communication

A B2 learner can:

explain opinions in detail;
argue for or against an idea;
discuss abstract topics;
participate in discussions;
negotiate;
explain advantages and disadvantages;
give presentations;
communicate effectively in professional contexts.
7.3 B2 Grammar

Possible areas include:

complex conditionals;
passive structures;
reported speech;
advanced modal structures;
complex relative clauses;
participle clauses;
advanced tense usage;
inversion in selected contexts;
complex sentence structures;
advanced conjunctions;
emphasis structures.

The emphasis should increasingly be on:

Accuracy
+
Appropriateness
+
Meaning
+
Context
7.4 B2 Vocabulary

Vocabulary should include:

abstract concepts;
professional contexts;
academic contexts;
society;
politics and culture where appropriate;
technology;
environment;
economics;
relationships;
media.

The learner should understand and use:

collocations;
phrasal verbs;
idioms;
word formation;
register differences.
7.5 B2 Reading

Texts may include:

opinion articles;
reports;
essays;
detailed articles;
professional communication;
longer narratives.

Tasks can require:

inference;
author's attitude;
implied meaning;
argument structure;
contextual vocabulary;
comparison of information.
7.6 B2 Listening

Listening may include:

interviews;
discussions;
presentations;
podcasts;
conversations;
longer talks.

Speech can be more natural and less predictable.

7.7 B2 Writing

Possible tasks:

essays;
reports;
reviews;
formal emails;
argumentative writing;
proposals.

The learner should demonstrate:

organization;
coherent argument;
appropriate register;
varied vocabulary;
grammatical control.
7.8 B2 Difficulty Characteristics

B2 activities should require greater independence.

They may include:

Longer texts
+
More natural audio
+
Abstract vocabulary
+
Less contextual support
+
Inference
+
Language choice
+
Argumentation
8. C1 — Advanced
8.1 General Description

C1 represents advanced and flexible use of English.

The learner can understand demanding texts and communicate effectively in social, academic and professional contexts.

The learner can use language flexibly without relying heavily on predictable structures.

8.2 C1 Communication

A C1 learner can:

express complex ideas;
explain subtle differences;
adapt language to context;
participate in professional discussions;
construct arguments;
summarize complex information;
express opinions precisely;
handle unfamiliar situations.
8.3 C1 Grammar

Grammar activities may involve:

advanced clause structures;
sophisticated conditional structures;
inversion;
emphasis;
complex passive structures;
advanced modal meaning;
participle clauses;
complex reported language;
nuanced tense choices;
grammatical variation.

The focus should be on precise and appropriate use rather than simply identifying rules.

8.4 C1 Vocabulary

Vocabulary should include:

abstract language;
academic vocabulary;
professional vocabulary;
idiomatic expressions;
advanced collocations;
nuanced word choice;
register;
synonyms with different connotations.
8.5 C1 Reading

Texts can be:

essays;
academic articles;
professional documents;
opinion pieces;
complex reports;
literary or journalistic extracts.

Tasks may require:

inference;
interpretation;
tone;
attitude;
rhetorical purpose;
subtle distinctions;
argument analysis.
8.6 C1 Listening

Listening may include:

lectures;
interviews;
debates;
presentations;
podcasts;
complex conversations.

The learner should cope with:

natural speed;
reduced forms;
varied accents;
implied meaning;
complex organization.
8.7 C1 Writing

Possible tasks:

formal essays;
reports;
proposals;
reviews;
academic-style responses;
professional communication.

Focus areas:

coherence;
precision;
register;
lexical variety;
grammatical control;
argument development.
8.8 C1 Difficulty Characteristics

C1 should increasingly test:

Precision
+
Nuance
+
Register
+
Inference
+
Complex language
+
Flexibility

The correct answer should not always be identifiable through a simple grammatical rule.

9. C2 — Proficient
9.1 General Description

C2 represents the highest CEFR level.

The learner can understand virtually everything heard or read and express themselves spontaneously, fluently and precisely.

C2 does not mean that the learner knows every word or never makes mistakes.

The emphasis is on extremely high overall control and flexibility.

9.2 C2 Communication

A C2 learner can:

understand complex communication;
interpret subtle meaning;
express nuanced opinions;
adapt register;
synthesize information;
formulate sophisticated arguments;
communicate naturally and precisely.
9.3 C2 Grammar

Grammar activities may focus on:

subtle differences in meaning;
sophisticated sentence structures;
stylistic variation;
complex transformations;
discourse-level choices;
grammatical nuance.

At this level, questions should avoid becoming artificial grammar puzzles.

9.4 C2 Vocabulary

Vocabulary may include:

highly advanced collocations;
idioms;
specialized terminology;
nuanced synonyms;
figurative language;
register;
connotation;
lexical precision.
9.5 C2 Reading

Texts may include:

complex essays;
academic texts;
professional documents;
literary texts;
sophisticated journalism;
argumentative texts.

Tasks may require understanding:

implicit meaning;
irony;
tone;
rhetorical strategies;
subtle distinctions;
complex arguments.
9.6 C2 Listening

Listening can include:

natural conversations;
lectures;
debates;
interviews;
complex presentations;
varied accents;
rapid or reduced speech.

The learner should be able to understand both explicit and implicit information.

9.7 C2 Writing

Writing tasks can include:

sophisticated arguments;
reports;
essays;
critical responses;
professional writing;
synthesis tasks.

Focus should include:

precision;
coherence;
style;
register;
nuance;
flexibility;
sophisticated vocabulary.
9.8 C2 Difficulty Characteristics

C2 should test:

Nuance
+
Precision
+
Flexibility
+
Register
+
Implicit meaning
+
Complex discourse
+
Natural language

The goal is not simply to make questions longer or more difficult.

10. Level Progression

The progression between levels should be understood as increasing independence and complexity.

A1
Basic survival communication
        ↓
A2
Everyday familiar communication
        ↓
B1
Independent communication
        ↓
B2
Confident and complex communication
        ↓
C1
Advanced flexible communication
        ↓
C2
Highly precise and nuanced communication
11. Level Boundaries

When creating a question, the content creator should ask:

What makes this question appropriate for this level?

A question should not be classified based only on one grammar structure.

Difficulty may depend on:

vocabulary;
grammar;
sentence length;
context;
inference;
task type;
amount of support;
audio speed;
accent;
abstractness;
response requirements.
12. Same Topic, Different Level

The same topic can appear at multiple CEFR levels.

For example:

Topic: Travel
A1

Where is the train station?

A2

What did you do on your trip?

B1

Describe a memorable trip and explain why you enjoyed it.

B2

What are the advantages and disadvantages of international tourism?

C1

How has mass tourism affected local communities?

C2

To what extent can tourism be reconciled with the preservation of cultural identity and local autonomy?

The topic itself does not determine the level.

The complexity of the language and task does.

13. Same Grammar, Different Level

A grammatical structure can appear at different levels depending on how it is used.

For example, the present perfect may appear in:

A2
Have you ever been to London?

B1
I've lived here for five years.

B2
I've been considering moving abroad for some time.

C1
The organization has increasingly come under pressure to reform.


Therefore:

Grammar topic ≠ automatic CEFR level

Question classification must consider the entire task.

14. Question Classification Principle

Every question should have metadata indicating its intended level.

Example:

level: B1
skill: Grammar
topic: Present Perfect
difficulty: medium

However, metadata must not be used as the only evidence.

Questions should be reviewed manually.

15. Difficulty Within a Level

Each CEFR level may contain internal difficulty variation.

Example:

B1
├── Easy B1
├── Medium B1
└── Difficult B1

This is useful for:

Diagnostic Tests;
question selection;
test balancing;
future adaptive testing.

Difficulty must not be confused with CEFR level.

A difficult A2 question is still an A2 question if the underlying ability being assessed is A2.

16. Diagnostic Level Estimation

The Diagnostic Test should use evidence from multiple levels.

Conceptually:

A1 evidence
A2 evidence
B1 evidence
B2 evidence
C1 evidence
C2 evidence
        ↓
Performance analysis
        ↓
Estimated overall level

The Diagnostic should not simply count how many questions the user answered correctly.

The final scoring model will define the exact methodology.

17. Level Test Principle

A Level Test for a specific level should primarily assess abilities associated with that level.

For example:

B1 Test

should not consist mostly of:

A2 questions

with a few difficult B2 questions added at the end.

Instead, it should contain a meaningful representation of B1 abilities.

18. Skill Variation

The same CEFR level can produce different skill profiles.

Example:

Overall B2

Reading:    C1
Grammar:    B2
Vocabulary: B2
Listening:  B1
Writing:    B2

This is expected.

The product should help users understand these differences rather than forcing every skill into the same level.

19. Content Creation Rule

Before creating a question, define:

Level
Skill
Topic
Learning objective
Question type
Expected answer
Difficulty

Example:

Level:
B1

Skill:
Grammar

Topic:
Past Simple vs Present Perfect

Objective:
Distinguish between completed past events and experiences connected to the present.

Question type:
Multiple choice

Difficulty:
Medium

This metadata will later allow the application to organize and select content programmatically.

20. Multimedia and CEFR Level

Multimedia difficulty must also be considered.

For audio:

A1
Slow, clear, familiar language

A2
Short everyday conversations

B1
Natural everyday conversations

B2
Longer natural speech

C1
Complex natural speech

C2
Highly natural and nuanced speech

For images:

Images can be used at all levels.

The difficulty comes from the task, not necessarily the image.

For example:

A1
Identify the object.

B1
Describe what is happening.

C1
Interpret the situation and explain the relationship between the people.
21. Level Selection for Vocabulary Practice

Vocabulary Practice should allow the user to explicitly select a level.

Example:

Vocabulary Practice

Choose your level:

A1
A2
B1
B2
C1
C2

The user should not need to take the Diagnostic Test first.

Vocabulary Practice is independent.

22. Level Descriptions in the UI

The user-facing descriptions should remain simple.

Example:

A1

Beginner — Understand and use very basic English in familiar situations.

A2

Elementary — Communicate in common everyday situations using simple English.

B1

Intermediate — Communicate independently about familiar topics and everyday situations.

B2

Upper-Intermediate — Communicate confidently about complex and abstract topics.

C1

Advanced — Use English flexibly and effectively in complex situations.

C2

Proficient — Communicate with a very high degree of precision, fluency and flexibility.

These short descriptions can be used in cards, menus and navigation.

23. Disclaimer

English Tests uses CEFR as a reference framework.

The application's results are estimates intended for educational and practice purposes.

They are not official CEFR certifications.

For academic, immigration, employment or other formal requirements, users should take an officially recognized examination when required.

Elementary

Upper-Intermediate

The central principle is:

A CEFR level represents ability, not simply a list of grammar topics.

Questions must therefore be classified according to the overall linguistic ability required to complete the task.
